SOCK SHOP - Architecture Microservices

Plateforme e-commerce évolutive avec système de recommandation IA

📌 Contexte

Développement d'une boutique en ligne de chaussettes utilisant une architecture microservices pour une scalabilité optimale.

  • Période : Depuis Décembre 2024
  • Client : Entreprise retail Française
  • Équipe : Projet assuré par SmartCloud AI
🛠 Technologies clés
Kubernetes Docker Terraform Python AWS

🎯 Objectifs

Scalabilité

Gérer 10 000 requêtes/minute pendant les pics

Recommandation

Système IA augmentant le panier moyen de 15%

Disponibilité

99.99% uptime avec monitoring temps réel

⚙️ Architecture Technique

Diagramme d'architecture microservices

Services Principaux
  • Service Catalogue (Node.js)
  • Service Paiement (Java Spring)
  • Service Recommandation (Python/ML)
  • Service Utilisateurs (Go)
Infrastructure
  • Cluster Kubernetes (EKS)
  • Base de données MongoDB
  • Redis pour le cache
  • Prometheus + Grafana
