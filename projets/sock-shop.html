Sock Shop - Architecture Microservices & DevOps

Mars 2025 - Présent DevOps • Cloud • Microservices

Contexte du projet

Projet réalisé dans le cadre de la Formation Ingénieur DevOps, consistant en le développement et déploiement d'une application e-commerce en microservices sur le Cloud, avec une approche DevOps pour une gestion optimale du cycle de vie de l'application.

Réalisations

Déploiement Cloud & Orchestration

  • Utilisation de Kubernetes (EKS/GKE/AKS) et Docker Swarm
  • Orchestration des conteneurs efficace et scalable

Automatisation CI/CD

  • Pipelines automatisés avec GitLab CI et GitHub Actions
  • Déploiements rapides, sûrs et reproductibles

Infrastructure as Code (IaC)

  • Automatisation du provisioning avec Terraform et Ansible
  • Gestion cohérente de l'environnement

Observabilité & Monitoring

  • Intégration de Prometheus, Grafana et ELK Stack
  • Surveillance des performances en temps réel

Compétences mobilisées

Kubernetes (EKS/GKE/AKS) Docker Swarm GitLab CI/GitHub Actions Terraform Ansible Prometheus Grafana ELK Stack
